# Toyota Certified Used Vehicle (TCUV) Program

> **last_verified**: 2026-05-18 (skill stress test iteration 5 + P0-P5 consolidation)
> **Data refresh schedule**: state rates / CPO programs / EV incentives / lease parameters should be re-verified annually or upon any user-cited deal that contradicts. The 2026-05-18 timestamp marks last full audit.

Toyota Certified Used Vehicles (TCUV) is Toyota's CPO program. Understanding eligibility and embedded value is critical for negotiations on 2019-2024 Toyota RAV4, Camry, Corolla, Highlander, Tacoma, Tundra, 4Runner, Sienna, Prius, and the Hybrid / PHEV variants. Hybrid coverage is the structural standout vs Subaru / Honda CPO — see § Hybrid Component Coverage below.

This file mirrors the structure of `subaru_cpo_program.md` and `honda_cpo_program.md`.

---

## Eligibility Criteria

Per Toyota Certified Used Vehicle program at toyotacertified.com:

| Criterion | Threshold |
|-----------|-----------|
| Age from original in-service date | **Max 6 years** (e.g., 2026 program covers 2020-2026 in-service vehicles) |
| Mileage | **Under 85,000 mi** |
| Inspection | Must pass Toyota's **160-point certified inspection** |
| Dealer | Must be sold by authorized Toyota dealer (not independent or off-brand) |
| Title / history | Clean title; no major accident on CARFAX / AutoCheck; no flood, salvage, fire, or rebuilt branding |

A 2022 Toyota RAV4 XLE with 32,000 mi sold by a Toyota dealer in 2026 is fully eligible (4 yr / 32k mi).

A 2020 Toyota RAV4 with 78,000 mi in 2026 is at the eligibility edge: 6 yr from in-service ≈ early 2026, miles still under 85k. Verify in-service date — a late-2020 in-service unit may have window until late 2026; early-2020 may already be ineligible by mid-2026.

A 2019 Toyota in 2026 is generally NOT TCUV eligible (>6 years from in-service). A 2018 Toyota is definitively ineligible.

### Single-tier program (vs Honda's two-tier)

Toyota TCUV is a single tier — unlike Honda True Certified which has Standard + Certified+ tiers. Toyota does NOT segment 4yr/48k cars into a premium tier; all eligible units get the same coverage package.

This simplifies negotiation: there is no "is this Certified or Certified+?" trim-up sales play to navigate.

## Coverage Granted (When Enrolled)

| Coverage | Term |
|----------|------|
| **Powertrain warranty extension** | **7 years / 100,000 miles** from original in-service date |
| **Limited bumper-to-bumper extension** | **1 year / 12,000 miles** after factory 3yr/36k expires |
| **Hybrid Components coverage** (Hybrid / PHEV models only) | **10 years / 150,000 miles** from original in-service date — see § Hybrid Component Coverage below |
| Deductible | $0 |
| Roadside Assistance | 1 year / unlimited mi 24/7 included |
| Transferable | Yes (to subsequent buyers within warranty period) |
| Trip Interruption | $50/day, up to $500 total |
| Rental Car Allowance | $35/day for covered repairs (max 5 days) |
| ToyotaCare | Some TCUV units include 1 yr / 25k mi free maintenance (oil changes, tire rotations, multi-point inspection) — verify with dealer; this is regional/year-dependent |

The 7yr/100k starts from the **original in-service date**, NOT the TCUV purchase date. So a 2022 RAV4 that went into service in 2022 has TCUV powertrain coverage through 2029 (7 years) or 100,000 mi, whichever comes first.

## Hybrid Component Coverage (RAV4 Hybrid / Camry Hybrid / Highlander Hybrid / Prius / Sienna Hybrid)

**This is the structural standout of TCUV vs Subaru CPO and Honda True Certified.**

For Hybrid and PHEV models, TCUV extends Hybrid-specific component coverage to **10 years / 150,000 miles** from original in-service date — Hybrid battery, hybrid control module, inverter, hybrid transaxle, hybrid coolant pumps. (Federal hybrid battery mandate is 8yr/100k for emissions-warranty states, 10yr/150k for CA-emission states; TCUV applies the 10/150k standard universally.)

Embedded value implication: replacing a Hybrid battery on a 2018+ RAV4 Hybrid out-of-warranty runs $2,500-$4,500 at a Toyota dealer. The TCUV 10yr/150k coverage on a 4-5 year old Hybrid with 60-80k mi has very real residual value — buyer essentially gets ~5 more years of hybrid-battery protection for free.

### Hybrid models where TCUV is most load-bearing

| Model | Hybrid battery replacement cost (out-of-warranty) | TCUV residual value impact |
|---|---|---|
| **RAV4 Hybrid** (2019-2024) | $2,800-$4,200 | High — most common model where this fires |
| **Camry Hybrid** (2020-2024) | $2,500-$3,800 | High |
| **Highlander Hybrid** (2020-2024) | $3,200-$4,800 | High (larger pack) |
| **Sienna Hybrid** (2021-2024) | $3,500-$5,200 | Very high — Hybrid-only platform on 2021+ Sienna |
| **Prius** (2019-2024) | $2,200-$3,500 | High |
| **RAV4 Prime** (2021-2024) PHEV | $4,500-$7,500 (larger 18kWh pack) | Very high |
| **bZ4X** (2023+ BEV — NOT hybrid) | n/a — full BEV, different warranty | See `ev_buyer_playbook.md` for BEV battery coverage |

For the RAV4 Hybrid PA example (new 2024 RAV4 Hybrid PA) — TCUV is not applicable at point of NEW purchase (TCUV is a USED CPO program). But the Hybrid Component coverage applies on TCUV resale 3-6 years later, making a TCUV'd 2024 RAV4 Hybrid more valuable on resale than a non-CPO equivalent.

## Embedded Value

Compare Toyota CPO (TCUV) to third-party extended powertrain warranties:

| Coverage Source | Cost |
|-----------------|------|
| Toyota TCUV (built-in) | Already in dealer price |
| Toyota Platinum VSA (Vehicle Service Agreement, separate post-TCUV) | $1,500-$3,000 layered on top |
| Third-party (CARCHEX, Endurance, Olive) | $1,800-$2,800 for equivalent 7/100k powertrain |
| Third-party hybrid-component-inclusive coverage | $2,500-$4,000 (limited providers cover hybrid components) |

**TCUV is functionally a $1,000-$2,000 embedded value for ICE Toyota** (similar to Honda True Certified $1,200-$1,800) when the dealer enrolls it as part of the sale.

**For Hybrid models, embedded value rises to $2,500-$4,000** because the 10yr/150k Hybrid Component coverage has no comparable third-party equivalent at reasonable cost. This is the structural arbitrage:

- ICE RAV4 + TCUV ≈ Honda CR-V + True Certified (embedded value approx the same)
- Hybrid RAV4 + TCUV >> non-hybrid CPO of equivalent class (TCUV adds $1,000-$2,500 of hybrid-component value that competitors do not match)

**Market premium typical**: **$1,000-$2,000 over identical non-CPO same VIN** at typical US Toyota dealers. Hybrid premium ($300-$700) often layers on top of CPO premium — but the Hybrid premium captures real hybrid-component residual value, not just dealer margin theater.

So buyer often nets **+$500 to +$1,500 of value** (ICE) or **+$1,500 to +$3,000** (Hybrid) after paying the TCUV premium.

## What TCUV Does NOT Cover

- Wear items (tires, brake pads, wiper blades, batteries — 12V starter, not hybrid traction battery)
- Accident damage (not warranty work)
- Cosmetic items (paint chips, interior wear, scratched alloys)
- Items modified or altered by aftermarket parts (tunes, lifts, non-Toyota audio, aftermarket suspension)
- Routine maintenance after the included ToyotaCare term (oil changes, filter services — separate program: ToyotaCare Plus extended)
- Pre-existing conditions documented at time of TCUV inspection
- **TCUV does not cover BEV battery on the bZ4X** — the BEV uses the standard Toyota BEV battery warranty (8yr/100k or 10yr/150k for CA-emission states), not TCUV. See `ev_buyer_playbook.md`.

## TCUV vs Non-CPO Math (worked example)

For a 2022 RAV4 Hybrid XLE AWD 32k mi (mid-US region):

| Scenario | Effective Cost |
|----------|---------------|
| **TCUV included** in dealer sale at $32,990 | $32,990 OTD basis (CPO + Hybrid coverage embedded) |
| Non-CPO same VIN at $31,490 (-$1,500) + buy Toyota Platinum VSA $2,200 + hybrid third-party rider $1,500 | $35,190 effective |
| Non-CPO same VIN at $31,490 + third-party 7/100k powertrain only $2,000 (no hybrid component coverage) | $33,490 effective with hybrid risk uncovered ($2,800-$4,200 expected-value exposure) |
| Non-CPO same VIN at $31,490 + self-insure (accept warranty + hybrid risk) | $31,490 net cost, accept ~$3,500-$5,000 of expected-value risk on hybrid component |

A non-CPO Hybrid Toyota priced $1,500 below the TCUV equivalent is roughly break-even after self-purchase of comparable ICE coverage — but the hybrid-component-protection gap means it's effectively WORSE for hybrid buyers. **For a Hybrid Toyota, TCUV is structurally hard to beat with self-insure math.**

For ICE Toyota (Tacoma, 4Runner, Camry non-hybrid, Corolla non-hybrid, ICE RAV4): the math is similar to Honda CR-V — TCUV wins if the dealer charges less than ~$1,500 premium over the non-CPO equivalent.

## Negotiating TCUV

If a Toyota is TCUV-eligible but the dealer has not enrolled it (sometimes happens with quick trade-in turnaround or recent acquisition):

> Could you enroll this vehicle in the Toyota Certified Used Vehicle program as part of the sale? This adds the 7yr/100k powertrain warranty extension, 1yr/12k limited B2B, and (for Hybrid models) the 10yr/150k Hybrid Component coverage. Standard Toyota-authorized dealer offering for sub-85k mi cars under 6 years from in-service.

Dealers can enroll a qualifying car for **~$500-$800 internal cost** (160-point inspection + program enrollment fee). They may accept this as part of the deal at no additional charge to you, especially if you've reduced your OTD ask elsewhere.

If the dealer charges separately for TCUV enrollment ($1,000-$1,500), it's usually still better value than buying third-party post-sale — especially for Hybrid models where third-party hybrid-component coverage is expensive and limited.

**Phase 6 negotiation play:** When a non-CPO 2020+ RAV4 Hybrid (or Camry Hybrid / Highlander Hybrid / Sienna Hybrid) is priced within $1,000 of a TCUV same-trim same-mileage comp, ask the non-CPO dealer to enroll TCUV at their cost as part of the deal. The hybrid-component coverage delta makes this the single highest-leverage margin give on Toyota Hybrid used-car negotiations.

## For Out-of-TCUV Cars (Over 6 Years or 85k+ mi)

A 2018 Toyota or any Toyota with 90k+ mi is ineligible for TCUV. Options:

1. **Toyota Platinum VSA (Vehicle Service Agreement)** — Toyota's separately-sold extended warranty. Plans 6/75k, 7/100k, 8/125k from time of purchase. For hybrid models, Toyota offers Hybrid VSA tiers covering hybrid components — these are the only OEM-grade hybrid extended warranties available.
   Typical Toyota dealer Platinum VSA pricing for a 7-year/100k-mile B2B plan on an out-of-TCUV 2018 RAV4 (~70-80k mi at purchase):
   - Powertrain only: approximately $1,800 to $2,500
   - Comprehensive B2B: approximately $2,800 to $3,800
   - Comprehensive B2B + Hybrid Components: approximately $3,500 to $4,800 (Hybrid models only; the hybrid component rider is $700-$1,000 additional)
2. **Third-party extended warranty** — buy elsewhere (CARCHEX / Endurance / Olive). For Hybrid Toyota, third-party hybrid coverage is limited — verify the plan explicitly covers hybrid battery, inverter, hybrid transaxle. Most generic "powertrain" third-party plans EXCLUDE hybrid components.
3. **Self-insure** — accept warranty risk. Toyotas are statistically very reliable (consistently top-3 in Consumer Reports brand reliability rankings), so this is a defensible choice for non-hybrid 2018+ Camry / Corolla / RAV4 with clean maintenance history. **NOT recommended for out-of-warranty Hybrid Toyota** — the hybrid battery replacement event is the structural risk that's hard to self-insure against.

For out-of-TCUV ICE cars, expect price to be ~$1,000 lower than a comparable TCUV car (lose embedded warranty). For out-of-TCUV Hybrid cars, expect ~$2,000-$3,500 lower (lose hybrid-component coverage in addition).

## TCUV Verification at Close

Confirm TCUV status before signing:

- [ ] **Toyota Certified Used Vehicle Certificate** (PDF) with VIN, vehicle data, in-service date
- [ ] **160-point inspection report** (signed by Toyota-certified tech, dated)
- [ ] Verify warranty start date matches original in-service date
- [ ] Confirm transferability documentation
- [ ] For Hybrid models: verify Hybrid Components 10yr/150k coverage is explicitly noted on the TCUV certificate (not just the standard 7yr/100k powertrain)
- [ ] Verify any included ToyotaCare 1yr/25k maintenance term — start date and what services are covered
- [ ] If dealer says "this is TCUV" but cannot produce certificate at close: walk or demand documentation before signing

Without these in hand, "TCUV" claims are unverified and the buyer may be paying TCUV pricing for non-CPO coverage.

## Toyota RAV4 / Camry / Highlander Specific Notes

### RAV4 (5th gen 2019-2024)
- 2019-2024 5th gen RAV4 is the most common RAV4 on used lots
- RAV4 Hybrid (2019+) qualifies for 10yr/150k Hybrid Component coverage — highest-leverage TCUV model class
- RAV4 Prime (2021+) PHEV qualifies for Hybrid Component coverage on the larger 18kWh pack
- AWD adds ~$1,500-$2,000 over FWD same trim, year, miles
- XSE, Adventure, TRD Off-Road trims have unique suspension/styling but same TCUV coverage

### Camry (8th gen 2018-2024)
- 2018-2024 8th gen Camry on used lots is mostly LE / SE / XSE / XLE
- Camry Hybrid (LE/SE/XLE Hybrid trims) qualifies for 10yr/150k Hybrid Component coverage
- Camry TRD (2020+) is the performance trim — non-hybrid only
- 2025 brings 9th gen Camry — used market for 8th gen will see step in supply

### Highlander (4th gen 2020-2024)
- 2020-2024 4th gen Highlander on used lots is L / LE / XLE / Limited / Platinum / XSE
- Highlander Hybrid qualifies for 10yr/150k Hybrid Component coverage — largest hybrid pack of the trio (RAV4 / Camry / Highlander)
- Highlander Hybrid Bronze Edition (2024) is a limited TRD-styled appearance package

### Sienna (4th gen 2021-2024)
- 2021+ Sienna is HYBRID ONLY — there is no ICE 4th gen Sienna. All used Sienna 2021+ qualifies for 10yr/150k Hybrid Component coverage if TCUV.
- This is the only Toyota model where every used unit is a hybrid candidate for the 10/150k coverage.

### Tacoma / Tundra / 4Runner (truck/SUV body-on-frame)
- TCUV applies but no hybrid component (ICE only on 4th gen Tacoma 2024+, 3rd gen Tundra 2022+, 5th gen 4Runner 2010-2024 — all ICE; 6th gen 4Runner 2025+ will introduce hybrid).
- Tundra 2022+ has i-FORCE MAX Hybrid trim — this WILL qualify for 10yr/150k Hybrid Component coverage on TCUV resale starting around 2025-2026.
- Pickup-truck-specific PPI items still apply — see `vertical_playbooks.md#part-1--pickup-truck-specifics` § 4 for Tundra V8 vs i-FORCE 3.5TT vs i-FORCE MAX Hybrid pre-purchase checks.

### Prius / Prius Prime
- 2019-2024 4th gen Prius / Prius Prime (5th gen 2023+)
- Always Hybrid (Prius) or PHEV (Prius Prime) — qualifies for 10yr/150k Hybrid Component coverage
- 5th gen Prius (2023+) has dramatically different styling and ~50% higher horsepower — verify trim matches buyer's expectation

### bZ4X (BEV — NOT hybrid)
- 2023+ bZ4X is full BEV (not Hybrid)
- TCUV applies to bZ4X but the BEV battery is covered by Toyota's BEV battery warranty (8yr/100k baseline; 10yr/150k in CA-emission states for the high-voltage battery), NOT by the Hybrid Component coverage.
- See `ev_buyer_playbook.md` for BEV-specific battery SoH thresholds and warranty mechanics.

## Related Toyota Programs

- **Toyota Platinum VSA** — Toyota's separately-sold extended warranty. Different from TCUV. Available at any age/mileage.
- **ToyotaCare** — included free maintenance (oil changes, tire rotations, multi-point inspection) for 2yr/25k mi from original in-service for NEW Toyota purchases; some TCUV units include a residual ToyotaCare term.
- **ToyotaCare Plus** — paid extended maintenance plan
- **Toyota Owner Loyalty Bonus** — for return Toyota customers; typically $500-$1,000 off MSRP on new
- **Toyota College Graduate Program** — $500 off new (selected models)
- **Toyota Military Rebate** — $500 off new
- **Toyota Friends & Family** — fleet/employee discount program

Most of these apply to NEW Toyota purchases. Used TCUV is its own thing, layered on top of the standard used-car sale.

## TCUV vs Subaru CPO vs Honda CPO — Quick Comparison

| Feature | Toyota TCUV | Honda True Certified | Subaru CPO |
|---|---|---|---|
| Age cap | 6 yr from in-service | 6 yr from in-service | 5 yr (current year + 4 preceding) |
| Mileage cap | 85k mi | 85k mi | 80k mi |
| Inspection | **160-point** | 150-point | 152-point |
| Powertrain extension | 7 yr / 100k from in-service | 7 yr / 100k from in-service | 7 yr / 100k from in-service |
| Limited B2B post-factory | 1 yr / 12k | 1 yr / 12k (standard) or 2 yr / 24k (Certified+) | None as standard CPO |
| **Hybrid Component coverage** | **10 yr / 150k (Hybrid/PHEV models only)** — unique to Toyota | n/a (Honda has no equivalent for CR-V Hybrid / Accord Hybrid) | n/a (Subaru has no plug-in hybrid current lineup; Crosstrek Hybrid retired) |
| Embedded value (ICE) | $1,000-$2,000 | $1,200-$1,800 | $2,000-$2,500 |
| Embedded value (Hybrid) | **$2,500-$4,000** | n/a | n/a |
| Market premium typical | $1,000-$2,000 (Hybrid +$300-$700) | $800-$1,500 | $1,500-$2,500 |
| Tier structure | Single tier | Two-tier (Standard + Certified+) | Single tier |

**Key structural difference**: TCUV's Hybrid Component 10yr/150k coverage is the strongest single OEM-CPO coverage line item across major brands. For a RAV4 Hybrid / Camry Hybrid / Highlander Hybrid / Sienna Hybrid / Prius buyer, TCUV is structurally hard to beat. For ICE Toyota, TCUV is comparable to Honda True Certified.
