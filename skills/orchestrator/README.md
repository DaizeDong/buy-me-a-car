# Buy Me a Car orchestrator

Read [SKILL.md](SKILL.md) for the current workflow and
[the repository README](../../README.md) for installation, dependencies and tests.

The orchestrator coordinates requirements, market research, inventory, authorized
outreach, inbox processing, negotiation, document review and close-day preparation.
It uses narrow helpers for specific tasks.

Real criteria and outputs live only in a verified private companion repository.
The bundled YAML demos and numbered examples are generated synthetic inputs.
Tax calculations have explicit jurisdictional support limits, external mail and
scheduling require host integrations, and PDF length depends on its content.
